**Internship:** Nexus Games  
**Role:** Game Development Intern  
**Dates:** June 2026 – August 2026  
**Team Size:** 5

## My Contributions

My primary responsibility was designing and implementing a new mine system for the game.

### Mine System

I developed six mine blast types and supporting gameplay systems, including:

- Six unique mine blast behaviors
- Multiplayer-synchronized mine behavior
- Stage-scaled mine spawning
- Persistent mines
- Mine chain reactions
- Scoring integration
- Visual and audio feedback
- Gameplay balancing and testing

The system was designed to integrate into the existing Polar Winds gameplay while adding additional hazards and interactions between players and the game board.

### Developer Tools

I also created development utilities to make testing later portions of the game faster and easier, including:

- Stage-skipping controls
- Board-state controls
- Tools for testing later-stage gameplay without replaying earlier stages

These tools reduced the amount of setup required when debugging and testing new gameplay behavior.

### Testing and Debugging

I participated in both:

- Self-testing of my own features
- Cross-team playtesting with another internship team

Testing feedback was used to identify bugs, adjust behavior, and refine the mine system.

## Development Experience

The internship required working within an unfamiliar existing codebase rather than starting a project from scratch.

I cloned and configured the shared project locally, learned the existing architecture, implemented new gameplay systems, tested changes, and worked within a collaborative Git-based development workflow.

## Project Outcome

At the end of the internship, our team presented the completed standalone prototype to Nexus Games internship leads.

The mine system was demonstrated as part of the final project, and the internship leads expressed interest in further development and potential integration of the system into the main game.
